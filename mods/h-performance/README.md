# H Performance (Fabric 1.21)

A small client-side low-render-load profile intended for PojavLauncher and lower-end Android devices.

## Default key
- `P` toggles Potato Performance on/off. Change it in Options -> Controls -> Key Binds -> H Performance.

## What it changes
- View distance: up to 5 chunks
- Simulation distance: up to 4 chunks
- Entity render distance scaling: up to 50%
- Particles: Minimal
- Clouds: Off
- Entity shadows: Off

The previous values are saved when enabling the profile and restored when disabling it. This is a settings profile, not a hardware overclock; actual FPS depends on device temperature, renderer, RAM, world, and server load. It does not alter server behavior.
